# Stock Market Data Analysis

An end-to-end data analysis project focused on analyzing historical stock market data using Excel, MySQL, and Power BI.

## Project Overview

This project analyzes stock market data to identify patterns and insights related to stock prices, trading volume, and profit and loss performance across different companies.

The project demonstrates the complete data analysis workflow, from data preparation and SQL-based analysis to interactive business intelligence dashboards.

## Tools & Technologies

* Excel
* MySQL
* Power BI
* Power Query
* DAX

## Project Objectives

* Analyze historical stock market data
* Understand company-wise stock performance
* Analyze closing prices and trading volume
* Compare profit and loss performance
* Create interactive dashboards for data-driven insights
