# Stock Market Data Analysis Report

## Overview

This folder contains the final project report for the Stock Market Data Analysis project.

The report documents the analysis workflow, including data preparation, SQL processing, Excel analysis, and Power BI dashboard development.

## Project Tools

* Microsoft Excel
* MySQL
* Power Query
* Power BI

## Report Contents

The report presents the project's methodology, analytical findings, company-level comparisons, and dashboard insights.

**Project focus:** Analyzing stock market data for five companies: HDFC, Infosys, Reliance, TCS, and Wipro.
