# Excel Data Preparation and Analysis

## 1. Overview

Excel was used to prepare, organize, and analyze stock market data before further processing with MySQL and Power BI.

The dataset contains 300 records covering five companies: Infosys, TCS, HDFC, Reliance, and Wipro. The final analytical dataset contains 12 columns, including four additional fields created for analysis.

## 2. Data Inspection and Preparation

The preparation process involved reviewing the dataset structure and checking its suitability for analysis.

The main checks included:

* Reviewing column names and data types.
* Checking date values and numerical fields.
* Checking for missing values and duplicate records.
* Preparing the dataset for calculations and analysis.

## 3. Analytical Columns

Four additional columns were used to support stock market analysis.

| Column               | Purpose                                       |
| -------------------- | --------------------------------------------- |
| Daily Return %       | Analyze daily stock price returns.            |
| 5-Day Moving Average | Examine short-term stock price trends.        |
| Profit Value         | Support numerical profit and loss analysis.   |
| Profit/Loss          | Classify records according to profit or loss. |

## 4. Exploratory Data Analysis

Excel was used to explore the dataset and compare stock market performance across companies.

The analysis included:

* Company-wise closing price comparison.
* Trading volume analysis.
* Profit and loss analysis.
* Comparison of company-level performance.

## 5. Pivot Tables and Charts

Pivot Tables and charts were used to summarize and visualize the dataset.

These summaries helped compare closing prices, trading volumes, and profit/loss performance across the five companies.

## 6. Outcome

Excel provided an initial view of the dataset and helped prepare it for further analysis using MySQL, SQL, Power Query, and Power BI.

The results supported the development of the project's interactive dashboards and business insights.
