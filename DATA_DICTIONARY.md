## 1. Dataset Overview

The stock market dataset contains 300 records and 12 columns. It is used to analyze stock prices, trading volume, daily returns, moving averages, and profit/loss performance across five companies.

The dataset was prepared and analyzed as part of an end-to-end data analytics project using Excel, MySQL, Power Query, and Power BI.

## 2. Original Columns

| Column    | Description                                             |
| --------- | ------------------------------------------------------- |
| Date      | Date associated with the stock market record.           |
| Company   | Name of the company represented in the record.          |
| Open      | Stock price at the opening of the trading session.      |
| High      | Highest stock price recorded during the session.        |
| Low       | Lowest stock price recorded during the session.         |
| Close     | Stock price at the close of the trading session.        |
| Adj Close | Adjusted closing price recorded in the dataset.         |
| Volume    | Number of shares traded, as represented in the dataset. |

## 3. Created Analytical Columns

| Column               | Description                                                           |
| -------------------- | --------------------------------------------------------------------- |
| Daily Return %       | Represents the daily percentage return calculated for the stock.      |
| 5-Day Moving Average | Represents the moving average of stock prices over a five-day period. |
| Profit Value         | Numerical value used for analyzing profit and loss performance.       |
| Profit/Loss          | Classifies each record as a profit or loss record.                    |

## 4. Data Preparation

The dataset preparation process included:

* Reviewing the dataset structure and column names.
* Checking record counts and data types.
* Validating date values and numerical fields.
* Checking for duplicate records and missing values.
* Creating additional analytical columns.
* Preparing the dataset for Excel analysis, MySQL processing, and Power BI reporting.

## 5. Dataset Usage

The prepared dataset supports the following analyses:

* Company-wise closing price comparison.
* Trading volume analysis.
* Stock price movement and trend analysis.
* Profit and loss distribution.
* Company-level performance comparison.
* Interactive Power BI dashboard reporting.
