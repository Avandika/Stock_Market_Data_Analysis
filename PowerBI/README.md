# Power BI Stock Market Analysis

This folder contains the Power BI dashboard developed for the Stock Market Data Analysis project.

## Dashboard Overview

The dashboard explores stock market performance across five companies: HDFC, Infosys, Reliance, TCS, and Wipro.

## Analysis Areas

* Executive Dashboard
* Price and Company Analysis
* Profit and Loss Analysis
* Company Details and Drill-through

## Tools and Techniques

* Power BI
* Power Query
* Data modeling
* DAX measures
* KPI cards and data visualizations

The dashboard presents stock market trends and company-level comparisons to support data exploration and reporting.
